# Morning Briefing — 아침 브리핑

[English](README.md) · **한국어**

> 임원층을 위한 매일 AI 한국어 브리핑 앱. 사용자가 늘어도 API 비용이 일정하게 유지되도록 공유 캐시 아키텍처로 설계했습니다.

📱 App Store에서 다운로드

---

## 왜 만들었나요?

매일 출퇴근에 왕복 두 시간 이상을 씁니다. 그 시간에 뉴스 피드를 스크롤하는 대신, 정말 중요한 것만 5분 안에 읽을 수 있는 무언가가 필요했습니다 — 일에 도움이 되는 경제·투자 맥락 같은 것들요.

어려운 건 UI가 아니라 비용 구조였습니다. LLM 기반 소비자 앱은 대부분 사용자별로 콘텐츠를 생성합니다. 그러면 API 지출이 사용자 수에 비례해서 늘어나죠. 혼자 운영하는 사이드 프로젝트에서는 사용자 50명쯤에서 수학이 깨집니다. UI를 짜기 전에 다른 아키텍처가 필요했습니다.

## 어떻게 동작하나요

**공유 일일 캐시.** 모든 사용자가 같은 날 같은 브리핑을 봅니다. 콘텐츠는 카테고리(경제, 투자)별로 하루에 한 번만 생성되고, 서버에 캐싱된 후 클라이언트의 `localStorage`에서 읽힙니다.

```
클라이언트 → localStorage("briefing_economy_2026-05-02") 확인
          → 캐시 미스 → POST /api/briefing
          → 캐시 히트 → 렌더링

서버      → 오늘 이미 생성되었나?
          → 예  → 캐시된 내용 제공
          → 아니오 → Claude 호출 → 저장 → 제공
```

결과: **사용자 수와 무관하게 API 비용이 하루 단위로 거의 고정됩니다.** 1000번째 사용자가 첫 번째 사용자와 같은 비용입니다.

**3단 카드 시스템.** 1번 카드는 무료, 2~3번 카드는 블러 처리된 페이월 — 사용자를 다시 오게 만드는 무료 가치와 명확한 업그레이드 경로를 동시에 제공합니다.

**iOS는 Capacitor로.** 같은 Next.js 코드베이스가 Capacitor 8을 통해 App Store에 네이티브 iOS 앱으로 출시되었습니다. 오프라인 지원, 푸시 알림, 로컬 알림, 배지 카운트까지 Capacitor 플러그인으로 처리합니다.

## 주요 기능

- 카테고리별 매일 갱신, 날짜 기반 키로 자동 캐시 무효화
- 서버 측 API 키 처리 — 클라이언트에 절대 노출되지 않음
- 스켈레톤 로딩 + 페이월 블러로 매끄러운 체감 성능
- Capacitor를 통한 iOS 네이티브 배포, 오프라인 모드와 푸시 알림 지원
- 5가지 에러 상태를 명시적으로 처리 (rate limit, 인증, 네트워크, 서버, 생성 실패)

## 배운 것

UI를 짜기 **전에** 캐시 레이어를 설계한 것이 이 프로젝트에서 가장 중요한 결정이었습니다. 몇 시간 만에 동작하는 UI와 첫날부터 지속 가능한 비용 구조를 동시에 가졌습니다. 사용자별 생성을 먼저 출시하고 나중에 캐시를 끼워 넣으려 했다면, 데이터 모델이 매 단계에서 저를 가로막았을 겁니다.

두 번째 교훈: 무료 카드 한 장만 제대로 보여주는 작은 페이월이 예상보다 훨씬 잘 전환됩니다. 사람들은 결제 결정 전에 무언가가 작동하는 걸 보고 싶어 합니다 — 모든 게 블러 처리되어 있으면 그냥 앱을 닫아버립니다.

## 기술 스택

`Next.js 16 (App Router)` · `React 19` · `TypeScript 5` · `Tailwind CSS 4` · `Anthropic Claude API` · `Capacitor 8 (iOS)` · `Vercel`

## 프로젝트 구조

```
src/
├── app/
│   ├── layout.tsx              한국어 메타데이터를 가진 루트 레이아웃
│   ├── page.tsx                홈 페이지 (클라이언트 컴포넌트)
│   └── api/briefing/route.ts   서버 측 Claude 엔드포인트
├── components/
│   ├── BriefingCard.tsx        페이월 지원 카드 컴포넌트

│   ├── CardSkeleton.tsx        로딩 스켈레톤

├── lib/
│   ├── claude.ts               Claude API 클라이언트

public/sw.js                    오프라인 모드용 서비스 워커
```
