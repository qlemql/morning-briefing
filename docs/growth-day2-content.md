## GeekNews / OKKY 게시글 초안

### 제목: AI가 매일 아침 뉴스를 3장 카드로 정리해주는 웹앱을 만들었습니다

안녕하세요. 사이드 프로젝트로 AI 아침 브리핑 서비스를 개발해서 공개합니다.

**사이트**: https://morning-briefing-mocha.vercel.app

**문제**: 매일 아침 뉴스를 챙기고 싶은데, 시간이 없거나 정보가 너무 많아서 핵심을 놓치는 경우가 많습니다.

**해결**: Claude API를 활용해서 매일 아침 경제/시사와 투자 뉴스를 3장의 카드로 정리해드립니다.

- 카드 1 (무료): 오늘 반드시 알아야 할 핵심 뉴스
- 카드 2: 그 뉴스가 내 삶에 미치는 영향 분석
- 카드 3: 바로 실행할 수 있는 인사이트

**기술 스택**: Next.js + TypeScript + Tailwind CSS + Claude API (서버 사이드)

서버 캐싱으로 하루 API 호출 2번이면 전체 유저를 서빙할 수 있어서 운영 비용이 월 $1 미만입니다. Vercel Cron Job으로 매일 아침 7시에 자동 생성됩니다.

피드백 환영합니다! 커피 한 잔 후원도 감사히 받겠습니다 ☕
