# 2달차 수익화 기술 스펙

## 수익 모델: 프리미엄 구독

### 현재 상태 (1달차 — 무료)
- 카드 1: 무료 공개
- 카드 2-3: KakaoPay 후원 후 잠금 해제 (소프트 페이월)
- HMAC 토큰 기반 서버사이드 콘텐츠 게이팅
- 하루 단위 unlock (일일 리셋)

### 목표 상태 (2달차 — 수익화)
- **무료 티어**: 카드 1만 제공 (현재와 동일)
- **프리미엄 티어** (월 2,900원 또는 3,900원):
  - 모든 카드 (1-3) 무제한
  - 알림 기능 (매일 아침 푸시)
  - 아카이브 (지난 브리핑 열람)

### 결제 연동 옵션 (사업자등록 필요)

| 옵션 | 수수료 | 난이도 | 비고 |
|------|--------|--------|------|
| Toss Payments | 3.3% | 중 | 정기결제 API |
| KakaoPay 정기결제 | 3.3% | 중 | 기존 연동 활용 |
| Portone (구 아임포트) | 0% + PG 수수료 | 중 | 통합 결제 |
| Buy Me a Coffee | 5% | 하 | 해외 서비스, 사업자등록 불필요 |

### 필요한 기술 작업

1. **사용자 인증 시스템**
   - 카카오 소셜 로그인 (가장 접근성 높음)
   - JWT 토큰 기반 세션
   - Vercel KV 또는 Redis로 구독 상태 관리

2. **결제 연동**
   - Toss Payments 정기결제 API
   - 웹훅으로 결제 상태 동기화
   - 구독 만료/갱신 자동 처리

3. **데이터베이스**
   - Vercel Postgres 또는 Supabase (무료 티어)
   - 테이블: users, subscriptions, briefing_archive
   - 브리핑 히스토리 저장 (아카이브 기능)

4. **푸시 알림**
   - Web Push API (PWA Service Worker 활용)
   - 매일 아침 7시 KST 브리핑 준비 완료 알림
