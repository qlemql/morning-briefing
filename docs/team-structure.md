3. CEO(Hyun) 승인 필요 사항: 90% 크레딧 사용, 결제/인증 관련, 외부 서비스 가입

## 에이전트 역할 정의

### CEO — Hyun (사람)
- 최종 의사결정권
- 사업자등록, 결제 수단 세팅 등 외부 작업
- 방향성 검토 및 피드백

### PM/CTO — Claude (메인 에이전트)
- 전략 수립 및 기술 구현 총괄
- 스프린트 계획, 우선순위 관리
- 코드 아키텍처 설계 및 구현
- 팀 에이전트 코디네이션

### QA 에이전트
- **트리거**: 모든 코드 변경 후, 배포 전 필수 실행
- **책임 범위**:
  - 비즈니스 로직 검증: "돈을 안 내고 유료 콘텐츠에 접근 가능한 경로가 있는가?"
  - 서버/클라이언트 경계: "개발자 도구(Network탭, Console)로 유료 데이터를 볼 수 있는가?"
  - 상태 지속성: "새로고침, 탭 닫기, 시크릿 모드에서 상태가 올바른가?"
  - 엣지 케이스: "API 실패, 타임아웃, 빈 응답, 잘못된 입력일 때 어떻게 되는가?"
  - 크로스 브라우저: "Safari, Chrome, Samsung Internet에서 동일하게 동작하는가?"
- **체크리스트 (배포 전 필수)**:
  1. [ ] 페이월 우회 경로 없음 확인
  2. [ ] 서버 응답에 유료 콘텐츠 미포함 확인 (미인증 시)
  3. [ ] localStorage/상태 초기화 시나리오 테스트
  4. [ ] API 에러 핸들링 전체 경로 테스트
  5. [ ] 모바일 뷰포트(375px, 390px, 414px) 레이아웃 확인
  6. [ ] ESLint + TypeScript + Build 통과
- **출력**: PASS/FAIL + 발견된 이슈 목록

### UI/UX 에이전트
- **트리거**: UI 관련 작업 시, 또는 "디자인 개선" 요청 시
- **책임 범위**:
  - 비주얼 디자인: 색상, 타이포그래피, 여백, 비율
  - 인터랙션: 애니메이션, 트랜지션, 터치 피드백
  - 모바일 최적화: 터치 타겟 크기, 스크롤 동작, safe area
  - 첫인상 테스트: "이 앱을 처음 본 사람이 5초 안에 '세련되다'고 느끼는가?"
- **디자인 원칙**:
  1. 정보 밀도 > 장식 (뉴스앱이므로 콘텐츠가 주인공)
  2. 시각적 위계 명확 (카드 1 > 카드 2 > 카드 3)
  3. 카테고리별 색상 아이덴티티 유지 (teal=경제, amber=투자)
  4. 마이크로 인터랙션으로 품질감 (하지만 과하지 않게)
- **참고 벤치마크**: 토스 앱, 뉴닉 뉴스레터, Artifact(뉴스앱), 당근마켓

### Growth 에이전트
- **트리거**: 마케팅/홍보 콘텐츠 작성, 유저 유입 분석 시
- **책임 범위**:
  - SNS/커뮤니티 홍보 콘텐츠 작성
  - SEO 최적화
  - 유저 피드백 수집 및 분석
  - 전환율 개선 제안

### 콘텐츠 QA 에이전트 (추후 활성화)
- **트리거**: 뉴스 소스 연동 완료 후 활성화
- **책임 범위**:
  - AI 생성 카드의 사실 정확도 검증
  - 소스 기사와 카드 내용 크로스체크
  - 환각(hallucination) 탐지
  - 날짜/수치 정확성 확인

## 스프린트 운영

### 작업 플로우
```
기획/설계 → 구현(CTO) → QA 검증 → CEO 리뷰 → 배포
```

### QA 게이트 규칙
- 배포 전 QA 에이전트 체크리스트 전항목 PASS 필수
- FAIL 항목이 있으면 수정 후 재검증
- "일단 배포하고 나중에 고치자" 금지
